# 1. 要件定義

## 1.1 目的

コンビニ 5 社（セブン-イレブン、ファミリーマート、ローソン、ミニストップ、デイリーヤマザキ）の新商品を一覧でき、実際に食べた人の口コミを読み書きできるサイトを運営する。広告とアフィリエイトで収益化する。

## 1.2 利用者

| 利用者 | できること |
|---|---|
| 閲覧者（未ログイン） | 商品・口コミ・週間まとめ・特集の閲覧、検索、バトルへの投票 |
| 会員（Google ログイン） | 口コミの投稿、Good / Bad、気になる、食べた記録、通知、通報、プロフィール設定、退会 |
| 管理者 | 収集結果の承認、商品・口コミ・ユーザーの管理、通報対応、特集の作成、各種設定 |

## 1.3 機能要件

| ID | 要件 | 優先度 |
|---|---|---|
| F-01 | コンビニ 5 社の新商品を自動で収集する（各社の新商品一覧ページのみ） | 必須 |
| F-02 | 収集結果をルールで整形する（税込価格、発売日、カテゴリ、食品以外の除外）。設定で Claude による仕上げを追加できる | 必須 |
| F-03 | 収集結果を承認待ちに入れる。設定で「承認せずに公開」に切り替えられ、その場合は重複の可能性があるものを自動で除外する | 必須 |
| F-04 | 収集は、各社の一覧が更新されたときだけ本処理を行う | 必須 |
| F-05 | 商品の一覧・検索・絞り込み（カテゴリ、チェーン）・並べ替え | 必須 |
| F-06 | 商品詳細（説明、価格、カロリー、発売日、販売地域、公式ページへのリンク） | 必須 |
| F-07 | 口コミの投稿（星、味・量・コスパ、本文、写真）とひとこと口コミ | 必須 |
| F-08 | 口コミへの Good / Bad と、レビュアーのランク表示 | 必須 |
| F-09 | Google ログイン、ニックネーム、プロフィール画像、年代・性別（公開するかを選べる） | 必須 |
| F-10 | 気になる（ブックマーク）、食べた記録、通知 | 必須 |
| F-11 | 週ごとの新商品まとめ、ジャンル別の新商品バトル（週 1 回自動作成、投票は 1 人 1 回） | 必須 |
| F-12 | 特集：管理者が作る特集と、地域限定の商品リスト | 必須 |
| F-13 | 通報と、管理者によるアカウント停止 | 必須 |
| F-14 | 管理画面（承認、商品、口コミ、通報、ユーザー、収集元、特集、設定、監査ログ） | 必須 |
| F-15 | 広告（AdSense）とアフィリエイト（Amazon、楽天）の表示。管理画面で ID を設定する | 必須 |
| F-16 | 発売から 1 か月を過ぎた商品を、口コミなどと一緒に自動で削除する | 必須 |
| F-17 | 使われていない画像を自動で削除する | 必須 |
| F-18 | PWA（ホーム画面への追加、オフライン時の案内） | 任意 |
| F-19 | 口コミの AI 要約、週 1 回のダイジェストメール、あなたへのおすすめ、実績バッジ | 任意 |

## 1.4 非機能要件

| 分類 | 要件 |
|---|---|
| 費用 | Cloudflare の無料枠〜月数百円で運用できること。画像は端末側で圧縮し、商品画像は保存せず各社の URL を参照する |
| 性能 | ページはサーバー側で描画し、初回表示を速くする。R2 の画像は 1 年間キャッシュする |
| 可用性 | テストが通らないコードは本番に出さない。デプロイに失敗しても前のバージョンが動き続ける |
| セキュリティ | 管理画面の多層防御、CSRF 対策、画像の形式チェック、セッショントークンのハッシュ保存、セキュリティヘッダー（→ [内部設計 4.6](04-internal-design.md#46-セキュリティ)） |
| 個人情報 | 取得するのは Google の識別子・メール・名前・画像 URL のみ。公開されるのはニックネームと、本人が公開を選んだ年代・性別だけ。退会で削除できる |
| 法令・規約 | 収集先の robots.txt を守り、1 サイト 1 ページ・間隔を空けて取得する。広告・アフィリエイトには「PR」「広告」を表示する（ステマ規制）。外部送信先を公表する（電気通信事業法） |
| 保守性 | 型チェックと自動テストを CI で実行する。設計書をリポジトリで管理する |
| 対応環境 | スマホ優先のレイアウト。最新の Chrome / Safari / Edge / Firefox |

## 1.5 制約と前提

- 収集元はコンビニ 5 社の公式サイトに限る。各社のページ構造が変わると収集できなくなる（0 件のときはエラーとして記録される）。
- 商品画像は各社のサーバーから直接表示する。各社の利用規約や画像の差し替えの影響を受ける。
- 商品は発売から約 1 か月で削除されるため、口コミも長期には残らない。
- 管理者権限は `ADMIN_EMAILS` に書いたメールアドレスの持ち主だけが得られる。画面から他人に付与する機能は持たない。

## 1.6 収益化の前提

| 手段 | 状態 | 必要な準備 |
|---|---|---|
| Google AdSense | 実装済み（設定でオン） | 審査の通過、`ads.txt`（自動生成）、運営者情報とプライバシーポリシーの記載 |
| Amazon アソシエイト・楽天アフィリエイト | 実装済み（ID を設定すると表示） | 各プログラムへの登録。通販で買えるカテゴリ（スナック、チョコ、ドリンク、麺）だけに表示 |
| 独自ドメイン | 未設定 | AdSense の審査は独自ドメインが前提。`workers.dev` のままでは通らない可能性が高い |
